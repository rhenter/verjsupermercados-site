# verjsupermercados-site

Site público do VERJ Supermercados (verjsupermercados.com.br).

Por enquanto é só uma página "em construção", em HTML e CSS puros, sem build.
No futuro este repositório vai receber o e-commerce.

## Rodar localmente

```sh
python3 -m http.server 8080
```

Abra http://localhost:8080.

## Estrutura

- `index.html`: página
- `styles.css`: estilos (cores do sistema VERJ, azul `#2450e0`)
- `favicon.svg`, `assets/logo.svg`: identidade VERJ

Qualquer hospedagem estática serve (Railway, Cloudflare Pages, GitHub Pages, Netlify).
